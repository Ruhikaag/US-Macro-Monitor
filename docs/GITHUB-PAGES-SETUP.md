# GitHub Pages Snapshot Setup

This publishes the Haver snapshot from the Windows helper to GitHub. GitHub Pages serves the dashboard and public snapshot; the page checks for a newly published snapshot every minute. The Windows helper fetches Haver once per hour while it is running. Indicator values change when Haver releases or revises observations, not continuously.

## Create the repository

1. Create a **public** GitHub repository for the dashboard. The site and its data will be visible to anyone with the link.
2. Upload the contents of this `docs` folder to the repository's `docs` folder on the `main` branch. Include `index.html`, `.nojekyll`, `GITHUB-PAGES-SETUP.md`, and `data/snapshot.json`.
3. In the repository, open **Settings > Pages**. Set the source to **Deploy from a branch**, select `main`, and select `/docs` as the folder. Save and wait for the Pages deployment to finish. The site URL is usually `https://OWNER.github.io/REPOSITORY/`.

## Allow the Windows helper to publish

1. Create a fine-grained personal access token in GitHub. Limit it to this repository and grant **Contents: Read and write**. The token can update repository files, so do not share it or commit it.
2. In Windows, open **Edit environment variables for your account** and add:
   - `GITHUB_PAGES_REPOSITORY` = `OWNER/REPOSITORY`
   - `GITHUB_PAGES_TOKEN` = the token value
   - `GITHUB_PAGES_BRANCH` = `main` (optional; this is the default)
3. Sign out and back in (or run `outputs/Open US Macro Monitor.bat`) so the hidden **US Macro Monitor** Windows scheduled task starts with your user environment variables. It runs `pythonw.exe` without a helper console and publishes when it starts, then hourly while you are signed in. The batch file opens the dashboard in a browser, but the scheduled task itself does not. Check `outputs/haver_labor_dashboard.log` for a `Published dashboard snapshot to GitHub` entry after a refresh.
4. The helper publishes `docs/data/snapshot.json` after every successful hourly Haver check, including when indicator values are unchanged, so the public data-update timestamp stays current. A failed Haver check is retried after five minutes. Leave the PC awake, online, signed in, and the helper running for hourly checks and publication. If the PC is shut down, asleep, offline, or not signed in, the shared site retains the last published data and labels updates older than three hours as overdue. If Haver fails before its first successful refresh after restart, the helper leaves the last public snapshot intact rather than publishing empty data.

## Notes

- GitHub Pages deployment can take a few minutes after each hourly snapshot commit. The page reloads the public JSON every minute. **Last data update** is the helper's latest successful Haver refresh and publication; **Checked** is when the viewer last retrieved the public snapshot, not a new data update.
- The **Check updates** button reloads the latest published snapshot; it does not force a Haver refresh.
- The local and GitHub Pages dashboards show the same headline indicators. The local page continues to use its Python API; GitHub Pages reads the published JSON snapshot.
- The top **Export CSV** button opens a date-range and indicator chooser, including **Select all indicators**. Export observations begin in 2000 (or an indicator's first available observation if later); source data is requested from 1998 so year-over-year and quarter-over-quarter values at the beginning of 2000 can be calculated. Monthly and quarterly observations are included if their period overlaps the selected dates. Only selected indicators with observations in that range are downloaded.
- The National Accounts (GDP) theme contains six quarterly series: real GDP, personal consumption expenditure, real private fixed investment, exports, imports, and real government consumption and investment. Each card shows the current and previous quarter's annualized growth and the year-over-year change.
- The remaining themes are listed as empty categories until their indicators are specified; the five headline tiles remain available independently of theme membership.
- Every theme has a **The story behind the numbers** block. Summaries are supplied manually in `THEME_SUMMARIES` in `outputs/haver_labor_dashboard.py`; only National Accounts (GDP) has a supplied summary so far. Other themes say "Summary to be added." The helper does not generate or rewrite the summaries from Haver data or news.
- **Recent news:** shows at most five newest, distinct US headlines per selected theme, including the publisher, date and direct article link. The helper checks public CNBC RSS feeds and Deloitte's public weekly news page on its hourly refresh; only headlines dated within seven days appear, and the browser also hides links once they age out. When nothing qualifies it says **No recent relevant news**. Reuters refuses automated access (HTTP 401), the Financial Times article checked here displayed only a subscription prompt (HTTP 403 for the helper), and The Economic Times [RSS terms](https://economictimes.indiatimes.com/rss.cms) prohibit republishing or aggregating its feed on a public website, so those publishers are not used. A source with a verified, readable public preview could be added if its terms permit headline display; no paywall access is bypassed. Feed failures are flagged, and the hosted site needs the Windows helper online to receive new links or edited summaries.
- Charts default to Q1 2018 (January 2018 for monthly and daily data) through the latest observation. The dialog opens on **Chart**, with settings hidden. Choose **Custom** to see **Axis options** first, then **Indicators**. Choose **X-axis from/to** dates (available history extends back to 2000), set either or both **Y-axis minimum/maximum** limits, then select **Apply changes** to return to the chart. Blank Y limits are automatic; **Reset** restores the default 2018-onward dates and automatic scale. Quarterly and monthly observations are included when their period overlaps the dates. Values outside custom Y limits are clipped visually, not changed or removed from the data.
- **Copy chart** copies the displayed axes as an image, including the indicator title, measure, units, and displayed period, for pasting into documents or presentations. Images are 1800 by 920 pixels. Copying requires a supported browser (such as Chrome or Edge) and clipboard permission on HTTPS or localhost; permission errors are shown in the dialog. There are no separate PNG or SVG download buttons. The chart dialog's **Download CSV** exports the selected date range regardless of Y limits. The shared `chart-tools.js` resource must be published alongside `index.html`.
- Chart clipping includes horizontal padding for endpoint markers and line caps in both the preview and copied image; custom Y-axis limits continue to clip values vertically.
- Charts for percent rate indicators, including unemployment and federal funds, show **Level** only; percent-change functions are not meaningful for these rates. Other supported indicators offer **Level**, **% Period**, and **% y/y**. **% Annual Rate** is also available for GDP, spending, investment, exports, imports, government consumption/investment, and the PCE price index. Level uses the original Haver source (GDP/spending in billions of chained 2017 dollars, SAAR; PCE in index points, 2017=100), not the already transformed growth rate. Period growth is `(current / previous - 1) x 100`; y/y compares the same quarter/month one year earlier, or the daily observation on or before the same date last year. Daily period growth compares the previous available day. Annual rate compounds quarterly growth by 4 or monthly growth by 12; it is not y/y growth.
- Switching chart measures preserves the chosen dates, restores automatic Y scaling, and updates the preview, copied image, units, and chart CSV. Undefined calculations (missing prior observations or a zero denominator) are left missing. Existing tile values and the top multi-indicator CSV export are unchanged. **Reset** restores the original measure as well as the default dates and axes.
- Under **Custom > Indicators**, **Add indicator** overlays one other available indicator. The original series remains teal and the added series remains Deloitte green (`#86bc25`), regardless of axis side. Each indicator has a **Left/Right** axis selector; defaults are original Left and added Right. You can swap sides, place a single indicator on the right, or put both on the same side. Indicators on the same side share a scale calculated from both sets of values and use that side's limits, interval, and decimals; no normalization or unit conversion is performed. Unused axes are not drawn. Both use the selected date range; different frequencies are aligned by actual period-end dates without resampling or inventing observations. A color-coded legend identifies each series, measure, unit, frequency, and axis. **Copy chart** includes both series; the chart CSV includes both indicators in separate observation rows. Select **None - single chart** or **Reset** to remove the comparison. If either indicator has no observations in the chosen range, an explicit error appears.
- **Left Y-axis interval** and **Right Y-axis interval** set the exact difference between tick values, such as 5 or 10. Leave blank to keep automatic ticks. An explicit minimum anchors the first tick; subsequent ticks advance by the interval without exceeding the maximum. Automatic bounds round outward to interval multiples. Intervals must be positive and finite, and at most 50 labels per axis are allowed; invalid settings show an explicit error and disable exports. **Reset** restores automatic intervals and default axis sides.
- **Left Y-axis decimals** and **Right Y-axis decimals** set axis labels to exactly 0–3 decimal places. Leave blank for **Auto** (at most 3 decimals), then choose **Apply changes**. Axis placement, bounds, tick intervals, and decimals carry into copied charts, do not change observations, tooltips, or CSV precision, and return to defaults with **Reset**. X-axis dates remain date labels.
- Never put the token in the repository, the batch file, or a screenshot. Anyone with access to the token could write to the repository.
